# Тестовый банк на Android

Банк можно запустить на S25 в [Termux](https://f-droid.org/en/packages/com.termux/). PostgreSQL и Python работают на телефоне. Покупатель обращается к локальному HTTPS-адресу, а касса подключается по сети при регистрации. Для S25 и Tab S9 FE выберите BLE.

## Установка

Установите Termux, откройте его и выполните:

```sh
pkg update && pkg upgrade
pkg install git
git clone https://github.com/yorickyeng/oasis-pay.git
cd oasis-pay
sh termux-oasis setup
```

При первой установке потребуется интернет для пакетов Termux и Python. База и ключи хранятся в личном каталоге Termux. PostgreSQL доступен через локальный сокет этого каталога.

## Запуск

1. Включите точку доступа S25 и подключите к ней Tab S9 FE. На планшете откройте детали текущей сети и найдите адрес шлюза. Это IPv4 S25 в сети точки доступа. В обычной Wi-Fi-сети вместо шлюза используйте IPv4, выданный самому S25.
2. В Termux запустите банк, подставив реальный адрес S25:

   ```sh
   cd ~/oasis-pay
   sh termux-oasis start 10.171.157.48
   ```

3. На S25 в кошельке укажите `https://127.0.0.1:8443`, отпечаток TLS и код покупателя из вывода команды. На планшете укажите выведенный сетевой URL, тот же отпечаток и код кассы. Нажмите «Проверить связь с банком» на обоих устройствах и зарегистрируйте их. После регистрации планшет может работать как офлайн-касса.
4. Переключитесь из Termux в Oasis Pay и проведите оплату. Оставьте сеанс Termux открытым. Для остановки вернитесь в Termux и нажмите Ctrl+C. Если нужно остановить и PostgreSQL, выполните `sh termux-oasis stop-db`.

Первый запуск создаёт отдельный тестовый банк с собственным ключом. Если Oasis Pay уже привязан к банку на Mac, для сохранения регистраций и платежей нужно перенести базу и ключи из его резервной копии. Для чистого теста используйте установку приложения без прежней регистрации. Перед сбросом данных приложения проверьте незавершённые счета.

При изменении IP S25 остановите банк и снова запустите его с новым IPv4. Файл сертификата и отпечаток обновятся, существующие ключи банка и записи базы сохранятся. Чтобы повторно посмотреть параметры, откройте второй сеанс Termux и выполните `sh termux-oasis show` из каталога проекта.
