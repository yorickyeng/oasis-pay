# Банк без USB

Независимо от выбранного транспорта, телефон обращается в банк по HTTPS. NFC и BLE связывают только телефон покупателя с кассой.

## По Wi-Fi

1. Подключите Mac и Android к одной личной сети. Запустите Docker Desktop и выполните `./oasis network`. На Mac команда выбирает IPv4 интерфейса Wi-Fi. Для сети с другим интерфейсом укажите нужный IP явно.
2. В приложении откройте параметры банка и вставьте актуальный блок `./oasis show`. Адрес должен содержать IP Mac, например `https://192.168.1.10:8443`. На Android 17 разрешите приложению доступ к локальной сети. Проверьте, что дата и время на обоих устройствах выставлены автоматически.
3. Нажмите **Проверить связь с банком**. Проверка HTTPS, сертификата, даты и состояния базы работает до регистрации, даже при выключенных NFC и Bluetooth. Если локальный Wi-Fi не имеет выхода в интернет и Android выбрал мобильные данные, приложение направит запрос к IP в непосредственно подключённой частной Wi-Fi-подсети через Wi-Fi. Активная VPN сохраняет свой маршрут.

| Результат | Что проверить |
| --- | --- |
| Банк не отвечает | `./oasis doctor` на Mac. У банка нужен статус healthy и доступный с сети порт. Привязка к 127.0.0.1 доступна с самого Mac. Проверьте IP Mac и сеть телефона. |
| Mac видит банк, Android сообщает о тайм-ауте | Возможны изоляция клиентов точки доступа или фильтрация входящего порта. Проверьте в личной сети или используйте частную VPN. |
| Ошибка защищённого соединения | Скопируйте свежий адрес и SHA-256 из `./oasis show` и проверьте часы. При смене сети выполните `./oasis network`. |
| Проверка проходит, подключение отклонено | Проверьте код выбранной роли и выберите тот же стенд, где устройство было зарегистрировано. |

## Если Wi-Fi изолирует устройства

На личных устройствах можно использовать [частную сеть Tailscale](https://tailscale.com/docs/how-to/connect-to-devices). Установите клиент на Mac и Android, войдите в одну частную сеть и скопируйте IPv4 Mac из Tailscale. На Mac, подставив этот адрес, выполните:

```sh
./oasis vpn 100.101.102.103
```

Команда публикует порт банка на указанном адресе частной сети, обновляет TLS и печатает новый блок настроек. Импортируйте его на Android при включённом Tailscale и повторите проверку. Регистрации и история остаются в том же банке. Для возврата к локальному Wi-Fi выполните `./oasis network` и импортируйте свежий блок.

Компьютер и устройства должны иметь доступ друг к другу в выбранной сети. Подключение по Tailscale требует входа в ваш аккаунт на каждом устройстве.
